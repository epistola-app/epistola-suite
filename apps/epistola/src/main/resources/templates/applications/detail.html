Roles

Every key of this application acts with these roles. They are fixed when the application is created.

Viewer

Every document Sees every document of the tenant, whichever system requested it: collected results, jobs and downloads.

Only its own Sees only the documents it requested itself; another application's are not found.

Owns unattributed documents Also sees the documents that record no application: those requested before applications existed, and those requested with a bearer token.

Documents that record no application — requested before applications existed, or with a bearer token — are not shown to it. They belong to Case system; giving them to this application takes them from it.
