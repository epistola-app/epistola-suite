From here to a document

An application such as GZAC makes documents from what is live in an environment. Three steps get it there.

  1. Add a template Done
    New template Adding a template needs the content author role.
  2. Publish it and make it live
    Publishing fixes what your application gets, so it stays the same while you keep working; the publish dialog makes it live in the environment you tick.
    There is no environment to make it live in yet. Add one, such as test, first.
    It is published: under Live below, choose the version and press Make live. Publishing needs the publisher role.
  3. Use it from your application
    Your application asks for catalog letters, template invoice and environment test. It signs in with an API key.
