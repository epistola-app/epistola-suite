# Apache Tomcat CVE-2026-41293 and CVE-2026-43512 (fixed by upgrading to 11.0.22)

Spring Boot 4.0.6 managed `org.apache.tomcat.embed:tomcat-embed-core` at 11.0.21, which Trivy
flagged CRITICAL for CVE-2026-41293 (improper input validation) and CVE-2026-43512
(digest-authentication bypass). Fixed by the `extra["tomcat.version"]` override pinning 11.0.22.
Shipped in **0.21.0**.

**Backfilled record**, written from the CHANGELOG entry and the build-file comment.
Reachability was never assessed — a fixed release existed and the bump was a drop-in — so the
status is `fixed`, not `not_affected`. We do not know whether the vulnerable code was
reachable, and this record does not pretend otherwise.

Superseded by [EPIS-DEP-2026-003](2026-09-03-epis-dep-2026-003.md), which found this pin had
by then become a downgrade relative to the Spring Boot BOM.
