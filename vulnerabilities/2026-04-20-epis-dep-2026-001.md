# Thymeleaf CVE-2026-40477 and CVE-2026-40478 (fixed by upgrading to 3.1.4.RELEASE)

Two expression-injection vulnerabilities in Thymeleaf, overridden to 3.1.4.RELEASE ahead of
the Spring Boot 4.0.6 BOM catching up. Shipped in **0.15.0**.

Worth keeping alongside the Tomcat records because it is the opposite case. Tomcat's
container-managed security is code we ship but never execute; Thymeleaf renders every UI
response the suite produces. There was no reachability argument to make and none was
attempted — the upgrade was the entire mitigation.
