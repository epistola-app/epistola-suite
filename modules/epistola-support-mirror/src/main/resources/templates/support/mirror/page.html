For each catalog this tenant shares, this installation sends Epistola the catalog's released versions: their full content, including images, fonts and other assets; the catalog's name and its version numbers; and to which environments each release is deployed, and whether those are production environments. With each release it also sends every release it depends on, from other catalogs too, because Epistola cannot render a release without them. A release that depends on a catalog marked "Never share" is not sent at all.

The system catalog and catalogs Epistola supplies with the suite are shared like any other. Content Epistola already holds is not uploaded again. Drafts and draft deployments are never sent, nor generated documents and the data they were made from.

Epistola uses the copy only to check these releases against new suite versions before it releases one. When a catalog stops being shared, or this tenant stops sharing, Epistola deletes what it holds of it at the next sync.
