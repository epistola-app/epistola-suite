Support requests always stay in this installation. With this tenant's consent, a support request also goes to Epistola support: at once when this installation hands new requests to Epistola support, or when its support desk passes one on. What is sent:

  • its title and description;
  • its category, priority and status;
  • the address of the page it was submitted from, including the query string;
  • the browser console log of that page (its last 100 entries);
  • browser metadata: application version, browser, language, platform, window and screen size;
  • the screenshot, when one was taken;
  • comments added to it later, and status changes. While this installation keeps its tenants confidential, whoever wrote a comment goes as a reference only; otherwise with their name and email address.

The tenant's key goes with it. Epistola support may reply with comments and status changes, which appear on the support requests here. The name of who submitted an item is not sent: it goes as a reference, the same for every request of one person, so Epistola can tell that requests come from one person, never who.

Consent applies to support requests submitted from the moment it is given. Requests submitted before that stay in this installation, also after consent is given. Withdrawing stops everything not sent yet; what Epistola already received stays there. Giving consent again carries on with support requests Epistola already received: what is written about it from then on is sent, and what was written while sharing was off never is.
