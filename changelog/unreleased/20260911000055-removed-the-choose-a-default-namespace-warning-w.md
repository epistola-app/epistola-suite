title: Removed the "choose a default namespace" warning, which no longer described anything.

A tenant default is now only the value a namespace picker starts on, so its absence is not a problem and nothing waits on it. The Exchange page says what it is for instead of warning about it, and the namespace field in the release dialog appears only when the release is actually being published.
