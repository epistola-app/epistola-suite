title: Browse Epistola Exchange and install from it.

A new page beside Subscribe and Import ZIP, because installing from Exchange is another way to get a catalog rather than a separate part of the product. Search, pick a version, install. The dialog says what a reader needs before deciding: that the catalog arrives as a read-only mirror, that a failed resource abandons the whole install rather than leaving it half done, and — before the attempt rather than through it — that the catalog ID is already taken, if it is. Only releases this tenant can actually install are offered, which matters because Exchange keeps returning withdrawn ones to whoever publishes the catalog. The Version column on the catalogs list now renders from the recorded check instead of a round-trip per row while the page loads, and gained a state for a release its publisher has withdrawn: still working, still yours, no longer offered — where the way forward may be an older release.
