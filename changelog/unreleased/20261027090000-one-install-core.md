title: Every received catalog is checked as an imported archive is.
---

A catalog installed or upgraded from its source URL, a registry or Exchange now goes through the same checks as an uploaded archive, inside one transaction: its fingerprint is recomputed, every image and font file must match its declared hash, and every reference must resolve. One that breaks a rule is refused whole, with the findings, where before it installed and failed later. A source that cannot be reached or answers 5xx shows as unreachable, not as a protocol error. A source with API-key authentication now also gets the key as `Authorization: ApiKey`, so one 2.0 suite can read a catalog from another.
