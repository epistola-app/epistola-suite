title: Catalogs speak of releases, and the next version is now the next release.
---

A catalog's published versions are called releases throughout the web UI and the MCP tool descriptions; "version" now only names a number, such as v1.2.0. The draft everyday work goes into is the Next release, and a draft can be named neither "Next release" nor "Next version". A catalog's Versions page is now Releases, at `…/releases`; links and bookmarks to the old `…/versions` address are redirected there permanently.
