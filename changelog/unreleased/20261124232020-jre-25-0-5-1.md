title: The images ship the BellSoft Liberica 25.0.5.1 JRE, fixing CVE-2026-114938 to CVE-2026-114942.
---

The Java runtime in the images moves from 25.0.5.0.3 to 25.0.5.1, which fixes Java4Shell
(CVE-2026-114938) and four other HIGH OpenJDK vulnerabilities. The images no longer start the JVM
with `-XX:-UseBASE64Intrinsics`, the 2.0.1 mitigation for Java4Shell. The Helm chart keeps it in
its default `jvm.options` for installations still running an older image.
