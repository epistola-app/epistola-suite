title: lineHeight in the PDF now matches the editor.
---

A `lineHeight` multiplier is meant as a multiple of the font size, as the editor shows it, but the
PDF renderer scaled the font's own line height instead, so the same value spaced lines differently
per font: `1.0` gave 1.11× the font size in Liberation Sans and about 1.45× in Inter. Newly
published versions use rendering defaults V6, where lines sit `fontSize × lineHeight` apart in any
font. Text in those versions sets tighter than before; with the default theme's `1.5`, by about a
tenth in Liberation Sans and more in fonts with tall ascenders. Versions published earlier keep
rendering as they did.
