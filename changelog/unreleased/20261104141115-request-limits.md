title: Lists, maps and the texts in them have limits, the same in the web UI, MCP and REST.
---

A variant has at most 50 attributes, each value at most 255 characters, as are an attribute's allowed values. A template has at most 100 data examples, each named in at most 255 characters. A theme has at most 100 block style presets, a draft at most 50 dependencies and 100 declared presets, and a release acknowledges at most 1000 versions it is behind. The REST API refuses more with a `validation-error` naming the field, as the 2.0 contract says, and the web UI and MCP now refuse it too, so nothing they write is something REST cannot take back in an update. Importing a catalog is not held to these limits: an archive that imported before still does.
