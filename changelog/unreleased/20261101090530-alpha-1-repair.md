scopes: [upgrade]
title: A database that 2.0.0-alpha.1 migrated needs a repair script.
---

Two upgrade steps were corrected after alpha.1, so 2.0 refuses to start on a database that alpha.1 migrated, and changes nothing. **Action on upgrade from alpha.1:** stop alpha.1 and run `docs/upgrades/2.0.0-alpha.1-repair.sql` once (Upgrades guide, "From 2.0.0-alpha.1"). A database upgraded from 1.x by a later version, or created from scratch, needs nothing.
