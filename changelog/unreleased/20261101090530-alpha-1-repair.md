title: A database 2.0.0-alpha.1 migrated needs a repair script before a later 2.0 version starts.
---

The upgrade from 1.x left out of the "Published in 1.x" draft a stencil 1.x never published that a published template used (1.x let a template use a stencil's draft), so that draft could not be released. The upgrade step that builds it is corrected, and because it changed, a later version refuses to start on any database alpha.1 migrated, changing nothing. **Action on upgrade from alpha.1:** stop alpha.1 and run `docs/upgrades/2.0.0-alpha.1-repair.sql` once (Upgrades guide, "From 2.0.0-alpha.1"); it records the corrected step and adds the missing stencils. A database rebuilt from 1.x or from scratch needs nothing.
