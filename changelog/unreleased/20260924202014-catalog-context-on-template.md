---
type: feat
scopes: [catalog, templates]
audience: user
title: A template page says which catalog it is in, and what has yet to be released.
---

A template page named no catalog at all: the back link went to the template list, and the only
mention of one was "belongs to a subscribed catalog", which did not say which. You could edit for an
hour without knowing whether your work was in a released version or waiting to be.

Every tab now carries the catalog it belongs to — named and linked — with the version it was last
released at, whether anything has changed since, and a release action where there is something to
release. The version shown is what the catalog was last released at, never what you are editing:
editing happens in the working copy, which has no version until you release it.
