title: Page headers and footers can go anywhere, in any number.
---

Headers and footers can now sit inside a stencil (a letterhead that carries them), a conditional or a loop, and page breaks start a new section. The editor labels each one with the pages it applies to. Existing documents and published versions keep their layout. Catalogs that use several footers need this version to import.
