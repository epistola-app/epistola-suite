title: Publishing a catalog says what changes and what that means, and picks the version number for you.
---

The Publish dialog lists what changes by name — "Added: Invoice (Template)" — and says what it means for whatever is connected: only corrections, new things that keep everything working, or a warning naming what can break. It picks the version number from that (corrections raise the last number, additions the middle one, breaking changes the first); you can change it under Advanced. Changes no longer have to be marked ready one by one first: publishing marks them. When nothing has changed, it says there is nothing to publish.
