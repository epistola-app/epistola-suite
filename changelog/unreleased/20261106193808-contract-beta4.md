A document is downloaded from `…/documents/{documentId}/content`. A preview names the release it
renders with `releaseId`, a draft or a released release, instead of `draft`. Discarding a draft that
something still relies on answers `catalog-draft-in-use`, with `dependents` naming the drafts of
other catalogs that build on it and `heldResources` the resources only it holds that something
outside it uses. A release's `draftsBehind` names each draft in full rather than by name. The
validation code for publishing a catalog in the `local` registry is now `CATALOG_REGISTRY_LOCAL`.
The text fields of an upload are validated: `importCatalog` takes its `registry` named in full, and
`~` is refused with `validation-error`.
