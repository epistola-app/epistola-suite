title: Smaller things a first-time user ran into, fixed.
---

A subscribed catalog's lists no longer offer **New** or **Upload**, which were refused once the form was filled in; images and fonts also no longer offer upload to people who may not upload. Publishing a fix to an older version says the number it gets, from the version it started from, instead of suggesting the patch after the latest release. The catalog page names the namespace an application must send, which the API requires, and labels what changed. The Generation page says where documents come from and links the API documentation, and its statuses read as words. The API key roles describe what they grant now. An environment named Production is no longer marked "Production" twice, a subscribed catalog that is up to date says so in words, and an environment page says that a draft can be deployed to it.
