title: Used by, and the check before an upgrade removes a resource, see every kind of use.
---

Both read the same record of what uses what now. **Used by** counted only another catalog's templates using a theme, a stencil or an image; it now also counts a theme's fonts, a variant's attributes, an attribute's code list and a stencil placed in a stencil. An upgrade, or a merge, that removes a resource another catalog still uses is refused for any of those uses; before, a stencil placed by another catalog's template was missed and removed from under it.
