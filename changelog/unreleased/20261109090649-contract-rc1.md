title: The REST API implements epistola-contract 2.0.0-rc.1, with available catalog releases listed a page at a time.
---

`GET …/catalogs/{registry}/{namespace}/{catalogKey}/available-releases` takes `page` and `size` and answers
with a `page` like every other list, so a catalog with many releases on offer is not cut short later.
Only the releases on the requested page are fetched from the source and described. The web UI and MCP
still list them all.
