title: MCP follows the 2.0 catalog model, and an assistant can deploy releases.

The template, stencil and data-contract version tools give way to `update_variant_content`, the `mark_*_ready` tools, `list_catalog_releases`, `get_catalog_changes`, `start_draft`, `rename_draft`, `discard_draft`, `preview_release_number`, `release_draft` and the catalog dependency tools; content tools take a `catalogVersion`. New: `deploy_release`, `undeploy_release` and `list_environments`, the merge tools (alpha) and registry tools (alpha). `create_catalog` takes a `namespace`, `list_catalogs` reports `editable` instead of `type`, and update tools take `expectedRevision`. Generating documents is still not offered: `preview_document` is the only rendering. **Action on upgrade:** update MCP prompts that name the old tools; see `docs/mcp.md`.
