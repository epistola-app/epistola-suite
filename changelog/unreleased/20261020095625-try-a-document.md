title: An environment's page can make a PDF of any deployed template, as applications get it there.
---

Trying a document used to mean calling the REST API, with its media type and namespace to get right first. An environment's page now has **Try a document**: choose one of the templates of the versions deployed there and **Make a PDF**. It is made with the template's first example data, from the version that environment serves, and opens in a new tab. Nothing is stored; it needs the permission to generate documents.
