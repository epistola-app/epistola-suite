title: PDF/A documents with accented text in a page header, page footer or address window render again.
---

Since 1.4.0, a PDF/A document failed to render when its page header, page footer or address window
held text such as "José Gómez" or "€", with "The 'é' glyph isn't defined in embedded font". That text
fell back to a non-embedded Helvetica, which iText 9.8.0 now rejects; before 1.4.0 the same documents
rendered but were not valid PDF/A. That text now uses the document's embedded default font, for every
published template version, without changing layout.
