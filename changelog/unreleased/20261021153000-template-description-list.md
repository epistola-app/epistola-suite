title: A template's description is shown in the template list and taken by the create dialog.
---

The _New Template_ dialog has an optional description field (at most 2000 characters), and the
template list shows a template's description as one line under its name, the full text on hover.
The MCP `list_templates` tool gives each template's `description`.
