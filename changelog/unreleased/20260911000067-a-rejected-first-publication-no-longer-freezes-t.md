title: A rejected first publication no longer freezes the catalog's namespace.
---

The namespace was fixed as soon as Exchange accepted the submission, but accepting a submission is not publishing it — a release Exchange then rejected left the catalog permanently bound to coordinates it had never occupied, and told its author a release had reached Exchange when none had. The namespace is now fixed on acceptance, so a rejected attempt leaves it as freely changeable as it was before.
