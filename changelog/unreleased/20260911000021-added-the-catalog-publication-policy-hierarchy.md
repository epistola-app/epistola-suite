Exchange publishing is an Alpha tenant feature that defaults off. Tenant administrators can choose whether authored catalogs publish by default, while each catalog can inherit, force publishing, default yes/no, or forbid publishing; non-hard policies support a per-release override. Catalogs can also prefer an Exchange namespace before their first immutable publication binding.
