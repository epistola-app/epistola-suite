title: Min height, vertical alignment, column styles and cell styles render in the PDF and have editor controls.
---

A container takes a **Min Height**. Table cells, data table columns and columns take a **Vertical Align**. Each column of a columns block can have its own background, padding, border and alignment, and the columns of a row are equally tall. Selected table cells can be styled again with **Cell Style**, which 1.5 hid. An image can **Keep with next**, so a logo or chart stays with the text after it. Templates that use none of these render as before.
