title: Bearer tokens on the REST API can be held to Epistola's audience, and the startup warns when they are not.
---

A JWT is checked for its issuer, so in an identity provider realm that serves other applications a
token issued to any of them is accepted, with the roles it carries. Set
`spring.security.oauth2.resourceserver.jwt.audiences` (Helm: `oidc.audiences`) and a token is
accepted only when its `aud` claim names one of them. Without it nothing changes, and the
application logs a warning at startup. Keycloak needs an audience mapper; see
`docs/keycloak-setup.md`, "API tokens and the audience". Recommended for every shared realm.
