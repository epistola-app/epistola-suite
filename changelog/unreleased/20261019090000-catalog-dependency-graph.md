type: feat
scopes: [catalog]
audience: user
title: A drawing shows which catalogs build on which.
---

**Dependencies** on the catalog list opens a drawing of every catalog of the tenant, with an arrow from each catalog to each catalog it uses, labelled with the versions it allows and the published version it is tied to; what everything builds on stands at the left, and a catalog the tenant does not have is drawn dashed. A catalog's Dependencies page shows the same drawing narrowed to that catalog: what it builds on and what builds on it, followed all the way, with the catalog highlighted. Each catalog in the drawing opens its own Dependencies page.
