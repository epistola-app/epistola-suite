title: An AI assistant can author and publish templates, stencils, themes, images and fonts over MCP (beta).
---

This lets an assistant convert an existing document, such as a Word template, into Epistola. Every write follows the same permissions and read-only-catalog rules as the UI and REST API, and activating a version in an environment stays in the UI. The tool arguments may still change in a minor release.
