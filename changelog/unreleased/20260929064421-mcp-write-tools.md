title: The MCP server can now author templates, stencils, themes, images and fonts (beta).
---

An AI assistant connected over MCP can now convert an existing document, such as a Word template,
into Epistola: create templates and variants, write variant drafts, set the draft data contract,
create stencils and their drafts, create and update themes, and upload images and font families.
`get_authoring_schemas` hands it the template-document, theme and style schemas to write against.
Every write goes through the same permissions and read-only-catalog rules as the UI and REST API,
so an API key only gains write tools for what its roles already allow. Publishing stays in the UI,
where a person reviews the result. The write tools are beta: their arguments may still change in a
minor release.
