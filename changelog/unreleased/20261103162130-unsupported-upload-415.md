title: An upload in a format that is not accepted answers 415, not 400.
---

Uploading an image whose type is not an image, or a file of a type the installation does not accept, answers `415 unsupported-media-type`, the status HTTP has for it, with the same explanation as before. **Action on upgrade:** a client that checks for `400` on such an upload checks for `415`.
