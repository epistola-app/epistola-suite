---
type: feat
scopes: [catalog]
audience: user
title: A catalog can be released from its own page.
---

The catalog page lists every release a catalog has cut, but the action that cuts one lived only in
the catalogs list — so the page you open to work on a catalog was the one place you could not release
it from. Releasing is now offered beside the release list, and a catalog with no releases says how to
cut its first instead of only why it would want one.
