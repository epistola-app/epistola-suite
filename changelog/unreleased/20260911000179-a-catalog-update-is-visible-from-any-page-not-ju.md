title: A catalog update is visible from any page, not just the catalogs one.
---

The navigation carries a count beside Catalogs, and the tenant home page names what is waiting and links to it. Both read the state the background check already recorded, so neither costs a call to anybody's server while a page renders — that is the whole reason the check persists what it finds. A release its publisher has withdrawn is called out separately and first: an available update is an opportunity, a withdrawn release is a fact about content already being used to generate documents. Nav items can now carry a count at all, which is new shared chrome any feature module can use.
