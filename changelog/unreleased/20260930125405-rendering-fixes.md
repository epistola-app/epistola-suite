title: Several styles and options now render as the editor promises.
---

Bold or italic set without a font keeps the theme's font. `letterSpacing`, a page background colour and "hide on first page" on a header now take effect. Inside a stencil, `$exists(params.x)` is false for a parameter without a value. These apply to versions published from this release, while earlier versions keep rendering as before; drafts and previews show them at once. The page format picker no longer offers `Custom`, which always rendered as A4.
