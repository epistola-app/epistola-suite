title: A tenant's home page shows where every catalog stands, and why documents cannot be made yet.
---

The home page now lists every catalog: what is being worked on (the next version, how many changes are not published yet, published versions it does not contain yet, and any long-term work), its latest published version, and which version each environment has deployed, each linking into that version. It also names every environment with nothing deployed, where every document request fails, with a link to deploy a version, and, while the upgrade from 1.x is still preparing catalogs, how many are left. This replaces the template, theme, environment and load test counts.
