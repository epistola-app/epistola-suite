title: Load test results are tracked over time.
---

`docs/load-test-results.md` logs each `epistola-load-test` run against a named hardware profile, so the effect of a change on throughput is visible rather than re-derived. Figures are only comparable within a profile, which is why the hardware is a first-class column rather than a footnote.
