title: Publish several catalogs can deploy what it publishes to an environment.
---

The Publish several catalogs page has a "Then deploy to" choice. Each catalog it publishes is deployed to
that environment straight after, beside what the environment already serves and with the releases it
needs, as a single catalog's publish dialog does. A deployment that is refused leaves the catalog
published, and the page says why it was not deployed.
