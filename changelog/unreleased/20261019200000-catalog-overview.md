title: A catalog's overview shows its open drafts and its environments as boxes.
---

The overview leads with the catalog's description and key, then a box per open draft: the next version with what is not published yet and Publish, and each parallel work with what it started from and Continue, each naming the environments that follow it. Below, a box per environment shows the version an application gets there, the draft it follows, or, when nothing is deployed, the latest published version; a newer published version is pointed out.
