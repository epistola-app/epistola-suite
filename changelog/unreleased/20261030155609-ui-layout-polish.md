title: A tidier interface - one primary action per page, labelled actions, sentence case and no clipped layouts.
---

Every row action is now a labelled button instead of a bare icon, labels read in sentence case, and the
catalogs page keeps New catalog beside a single More menu instead of seven equal buttons. The tenants
page lists tenants first and creates one in a dialog. Pages are named as the menu names them, a
supplied catalog says it is read-only once instead of on every row, and an empty catalog invites a
first template. Page headers, the What's New card, the cluster page and the catalog lists no longer
clip or overflow at ordinary widths, and the feedback button no longer covers a page's last row. A template's new API tab shows what an application sends to generate it: its identifiers, a request body per variant to copy, and whether a release is live for it to get.
