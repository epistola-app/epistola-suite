title: The REST API implements epistola-contract 2.0.0, built on catalog releases.
---

Template versions, variant drafts, contract drafts, stencil versions and environment activations are gone. Every catalog resource is under `/tenants/{tenantKey}/catalogs/{registry}/{namespace}/{catalogKey}/releases/{release}/…`, where `{release}` is `next`, a release id or a release number; writes need a draft, and reads answer any release. `key` is a resource's only address, and content is read and replaced through `/content`. New operations cover releases, dependencies, deployments and available releases. Generation, preview and validation take `versionRange` and `environmentKey`, and documents report the `version` and `releaseId` they were rendered from. Responses use `application/vnd.epistola.v2+json`. **Action on upgrade:** move REST clients to contract 2.0.0; the 2.0 client libraries follow it.
