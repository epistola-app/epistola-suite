type: fix
scopes: [catalog]
audience: user
title: Saving into a draft that was released meanwhile says so and offers the next draft.
---

When a draft is released while it is still open somewhere, a change made there is refused as such:
"This version has been released; open the next draft" (409 `catalog-version-released`, in the UI,
REST and MCP), where it used to say the draft did not exist. The template editor offers to open the
same page in the next draft. Behind it, every writer of a version's rows refuses a released version
(ADR 0036, step (f)).
