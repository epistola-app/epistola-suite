title: Each publication links straight to itself on Exchange.
---

Suite records what it sent and what it was told; Exchange is the only side that knows what became of it, and following that up meant finding the catalog there by hand. The catalog page now links each queued release directly to its submission on Exchange. It links to the submission rather than the release deliberately: a submission page exists from the moment Exchange takes the bytes and survives every outcome, so it answers "what happened to this?" for a refused or still-undecided publication too — which is when the question actually gets asked.
