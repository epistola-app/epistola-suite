title: Any release can be published to Exchange, not only the latest.
---

Publishing sent whichever release the catalog was currently on, so a version you had moved past could
never be sent. That was a consequence of rebuilding the archive from the working copy — only the
current release could match it — rather than a decision. A release carries its own content now, so
the release list offers each one for publishing, and a catalog whose author has moved on can still
send the version people are asking for.

A release cut before Epistola kept release content can still only be published while it is the
current one, and says so.
