---
type: fix
scopes: [themes, code-lists, environments]
audience: user
title: A theme, code list or environment can no longer be created with the key `new`.
---

`new` is where those list pages open the create form, so a theme, code list or environment keyed
`new` was listed but could never be opened. Creating one is now refused, in the create dialogs, the
REST API and MCP, as templates, variants and stencils already were. One that already exists, or
arrives in a catalog import, is still accepted and still renders; its page stays out of reach in the
UI, as before.
