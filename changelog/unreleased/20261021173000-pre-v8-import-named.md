title: An archive from before wire v8 is imported under the registry and namespace you name, never a guessed one.
---

A catalog archive exported before catalogs named their registry and namespace was put in the
importing tenant's namespace on the default registry without a word, giving the catalog a name it
then kept everywhere. The web UI's _Import ZIP_ now asks for both, proposing `local` and the tenant's
namespace, the name the upgrade gave the tenant's own catalogs, so an export from 1.x lands on the
catalog it came from. REST `importCatalog` takes `registry` (`~` for the default) and `namespace`,
which it answered as not implemented before: required for such an archive (400 without), and for a
current archive refused when they differ from what it names, since an import never renames a
catalog.
