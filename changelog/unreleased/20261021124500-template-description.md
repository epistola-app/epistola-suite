---
type: feat
scopes: [templates, catalog, api, mcp]
audience: user
title: Templates and variants have a description that travels with the catalog.
---

A template carries plain-text notes for its authors, up to 2000 characters and never rendered: what it is for, design decisions, known gaps. It is set in the create dialog and on the settings tab, shown under the template's name in the list, and available over REST and MCP. A variant's description, which a release used to lose, is kept too.
