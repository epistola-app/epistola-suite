title: The nightly content sweep no longer scans every asset to reclaim one blob.
---

Reclaiming unreferenced image and font bytes asks, for each candidate blob, whether any asset still
points at it. `assets` had no index on the content hash, so on an installation with many assets that
question was answered by scanning them — once for the sweep and again for the metric that follows it.

The orphaned-blob gauge also counted uploads that were still in flight, which are not orphans. It now
counts only what the sweep should have reclaimed and did not, so a healthy installation reads zero
and a genuine leak is visible instead of buried in noise.
