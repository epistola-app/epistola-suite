title: Contract 2.0.0-alpha.2 — a variant's description travels with a release, and image upload has no sensitive flag.
---

The suite builds against contract `2.0.0-alpha.2`. A template variant's description is now part of
its released form (`VariantEntry.description`): a release carries it, its fingerprint covers it, and
installing or receiving a release keeps it. A migration moves the description of every draft variant
into place; a release cut earlier keeps it as it showed it.

Every catalog resource can carry `tags` in the wire form (stencils did already); the other types do
not yet offer tags in the UI.

The REST image upload no longer takes `sensitive`: every image's bytes are stored once per
installation.

The demo catalog is 6.5.0: the Dutch variant of `simple-letter` has a description.
