title: The editor walkthrough is on by default.
---

The `editor-walkthrough` feature toggle now defaults to on, so new users see the Guide button and, on their first visit, a single pointer to it. The tour still never starts by itself. Switch it off per tenant on the feature toggles page, or for the whole installation with `epistola.features.editor-walkthrough=false`.
